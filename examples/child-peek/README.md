# Example: child-peek ("Even Better")

A 17.5-second micro-story, the phase A pilot. It shows the pipeline's
front end in order, each file produced by one skill in `skills/`:

| Step | Skill | File |
|---|---|---|
| 1 | `story-writer` | `story.json`: change, structure (kishōtenketsu), character, setting, tone, style profile |
| 2 | `screenplay` | `screenplay.json` and `screenplay.fountain`: one scene, five beats with intended effects and narration |
| 3 | `script-doctor` | `doctor-notes.md`: rated notes; the screenplay files are the revised version |
| 4 | `shot-list` | `shots.json`: five shots with size, angle, lens, composition, layers, key, light, parallax and continuity |
| 5 | `sound-design` | `sound.json`: not written yet (bead am-mcd.15); the skill's worked example is the plan |
| 6 | scene blocking | `scenes/sh1.json` to `sh5.json`: portrait (180 x 320) scene records with fixed cameras; `boards.png` is the first-draft contact sheet |

Status: story, beats and shots approved 2026-11-24. Boards are a first draft:
no value pass, lighting, character layer or headlight glow yet, and the wall
needs a depth bias. Next: narration, animatic with parallax, captions.
